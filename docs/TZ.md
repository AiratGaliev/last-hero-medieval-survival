# ТЗ: «Tiny Sword Survivors»

Клон Vampire Survivors на ассетах Tiny Swords (Pixel Frog)

| Параметр | Значение |
|---|---|
| Название | Tiny Sword Survivors |
| Жанр | Bullet-heaven / auto-shooter roguelite (экшен, выживание) |
| Референс | Vampire Survivors |
| Ассеты | Tiny Swords (Pixel Frog, itch.io, free) — `public/assets/tiny-swords/` |
| Движок | Phaser 4.2.1 (последняя версия, WebGL) |
| Платформа | Web (desktop + mobile), Next.js 16 / TypeScript |
| Язык UI | Русский |
| Длительность матча | 15 минут до победы (финальный босс) |

---

## 1. Основной игровой цикл

1. Игрок управляет **Синим Воином** (warrior, фракция blue), перемещаясь по арене.
2. Оружие атакует **автоматически** — цели выбираются без участия игрока.
3. Волны врагов спавнятся за пределами экрана и усиливаются каждую минуту.
4. Убитые враги дропают **кристаллы опыта (XP)**, которые притягиваются к игроку.
5. При достижении нового уровня игра **ставится на паузу** и предлагается выбор 1 из 3 карт улучшений (новое оружие / уровень оружия / пассивка).
6. Каждые 5 минут появляется **элита**, на 15-й минуте — **финальный босс**. Победа = убить босса.
7. Смерть игрока → экран Game Over со статистикой и отправкой результата в таблицу рекордов.

## 2. Игрок

| Характеристика | Начальное значение |
|---|---|
| HP | 100 |
| Скорость | 200 px/с |
| Радиус подбора XP | 70 px (магнит) |
| iFrames после урона | 500 мс (мигание) |
| Стартовое оружие | Меч (уровень 1) |

**Управление:**
- WASD / стрелки — движение (8 направлений, нормализация по диагонали)
- Esc / P — пауза
- M — вкл/выкл звук
- Мобильные: виртуальный джойстик (touch), кнопка паузы
- Весь бой автоматический (как в VS)

**Арена:** ограниченный мир 3200×3200 px, травяная плитка 64px + декорации (деревья, камни, кусты, здания). Камера следит за игроком, не выходит за границы. Вода по периметру (визуальная граница).

## 7. XP и левел-ап

- Дроп: обычный враг — камень XP (1 XP), brute/archer — жёлтый камень (3 XP), элита — красный (25 XP), свита босса (5 XP).
- Кривая: `XP(next) = 5 + level*10 + level^2*1.2` (лвл 1→2: ~16 XP, плавное усложнение).
- Магнит притягивает камни со скоростью 420 px/с при входе в радиус.
- Левел-ап: пауза мира + 3 карты (Phaser UI: бумага regularpaper/specialpaper + иконка + название + описание + текущий→новый уровень).

## 8. UI / Экраны

1. **Главное меню** (Phaser): логотип «Tiny Sword Survivors» (sword banner), кнопки: Играть, Как играть, Таблица рекордов; анимированный фон (юниты, облака). Кнопки из ассетов ui/buttons.
2. **HUD**: HP-бар (bigbar) над персонажем + слева-сверху панель: таймер, уровень, убийства; XP-бар (smallbar) во всю ширину сверху; иконки оружий/пассивок с уровнями.
3. **Пауза**: затемнение + Продолжить / Заново / В меню.
4. **Левел-ап**: 3 карты + заголовок на ленте (ribbon).
5. **Game Over**: статистика (время, убийства, уровень, счёт), поле имени, отправка рекорда, рестарт.
6. **Победа**: то же + «ПОБЕДА».
7. **React-обёртка**: шапка страницы, футер (контролы, атрибуция Pixel Frog), таблица рекордов под канвасом (shadcn/ui, загрузка из API).

**Счёт**: `kills*10 + minutes*100 + level*50 + bossBonus*5000 + gold`.

## 9. Аудио

Процедурные SFX на WebAudio (без внешних файлов): удар, выстрел, подбор XP, левел-ап, урон игроку, смерть врага, взрыв, босс. Лёгкая фоновая мелодия (секвенсор, тихий чиптюн-луп). Кнопка mute (M).

## 10. Бэкенд / БД (Prisma + SQLite)

- Модель `GameResult`: id, name, score, kills, level, timeSurvived, victory, createdAt.
- `POST /api/scores` — сохранить результат; `GET /api/scores?limit=10` — топ рекордов.
- React-компонент таблицы рекордов на странице.

## 11. Производительность

- Пуллинг снарядов/камней XP/чисел урона (без GC-спайков).
- Отключение анимаций урона вне экрана, despawn врагов дальше 1300 px.
- Физика Arcade, `overlap` вместо дорогостоящих коллайдеров между врагами (лёгкая сепарация группой).
- Кап 220 врагов, 400 снарядов, 600 XP-камней.

## Обновление v1.3 (раунд 4: глубокое QA + доработка)

### 0. Найдено и исправлено багов (глубокий QA-прогон через agent-browser)
1. **Критический: утечка ножей** — пул ножей не обновлялся в `Projectiles.update()`, «промахнувшиеся» ножи летели вечно (за минуты — тысячи активных физобъектов на координатах ±37000). Фикс: ножи истекают по life (560 мс).
2. **Золотые кристаллы не давали ничего** — дроп (3% с врагов) был чисто декоративным (xp=0, золота не было). Фикс: подбор даёт 3–8 золота с всплывающим «+N ЗОЛОТА».
3. **Оверлеи не перестраивались при ресайзе окна** (поворот телефона): кнопки Паузы/LevelUp/GameOver уезжали за экран. Фикс: сцены перезапускаются с теми же данными (LevelUp кэширует текущий набор карт — при ресайзе показываются ТЕ ЖЕ карты).
4. **Мобильные меню/левел-ап переполняли канвас**: заголовок наезжал на карточки, нижние кнопки обрезались. Фикс: виртуальное полотно (460×800 / 460×780) + зум камеры — контент скейлится целиком (проверено пиксельным анализом).
5. **Хардкод размера мира 3200 в Pickups** — заменён на константу WORLD.SIZE.
